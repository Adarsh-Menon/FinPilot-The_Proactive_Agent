## Deliberate limits

The app models one consolidated cash account and five two-decimal currencies. Forecasts use the explicitly supplied history range and dated upcoming flows; they do not infer future income. They are labeled as estimates (or provisional when history is under 60 days) and never return an affordability approval. Source versions invalidate old scenarios after ledger/context changes. The graph has no durable interrupt/checkpointer yet.

SQLite is a local convenience exception to the PostgreSQL deployment plan. It provides service-layer ownership checks, not database RLS. The API refuses environments other than `local` or `test`. Development cookies are non-Secure on loopback HTTP; production settings, deployment and privacy gates must be implemented before real service operation.

Next implementation increment: calibrate DeepEval judge metrics against human labels, re-run the 100-case advisor evaluation on release v19, expand forecast backtest personas and horizons (60/90 days), and add durable agent checkpoints and scheduled proactive delivery. See the [full roadmap](implementation-plan.md).
